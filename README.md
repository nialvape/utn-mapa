# utn-mapa

Mapa 3D de la sede Campus de UTN FRBA: aulas numeradas por piso y dónde cursa cada comisión según la cartelera de bedelía.

Next.js + react-three-fiber. Se sirve en `utnmcp.com.ar/mapa` (`basePath: '/mapa'`).

```bash
npm install
npm run dev   # http://localhost:3000/mapa
```

Planos de base: `Aulas_Sede_Campus.pdf` (CEIT).
